 Healthcare Patient Data Analysis
Problem Statement
Healthcare data is often collected but not properly analyzed, leading to missed insights about patient conditions, hospital performance, and treatment trends.

This project explores patient records to uncover patterns that can help improve healthcare decision-making.

---
 Objective
To analyze healthcare patient data using Excel in order to:
- Identify trends in patient demographics
- Understand common medical conditions
- Detect patterns in admissions and outcomes
- Create meaningful insights for better reporting

---

Tools Used
- Microsoft Excel
- Pivot Tables
- Charts & Graphs
- Data Cleaning Techniques
- Conditional Formatting

---

 Data Preparation
Before analysis, the dataset was cleaned by:
- Removing duplicate records
- Handling missing values
- Standardizing inconsistent entries
- Formatting dates and categories properly

---

 Key Analysis Performed
- Patient distribution by age group
- Most common medical conditions
- Gender-based analysis of conditions

---

 Key Insights
- Certain age group are more prone to some illness 
- A small number of conditions account for most patient cases
- Admission trends vary across time periods
- Data inconsistencies were reducing reporting accuracy before cleaning

---

Visualizations Included
- Patient demographic breakdown charts
- Condition frequency bar charts
- Admission trend line graphs
- Gender comparison visuals

---
 Impact
This analysis demonstrates how raw healthcare data can be transformed into clear, actionable insights that improve reporting accuracy and decision-making.
